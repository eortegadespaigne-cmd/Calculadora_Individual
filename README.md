# Calculadora en Python

## Descripción
Proyecto individual desarrollado en Python que implementa una calculadora básica utilizando módulos y funciones.

## Funcionalidades
La calculadora permite realizar las siguientes operaciones:

- **Suma:** suma dos números.
- **Resta:** resta dos números.
- **Multiplicación:** multiplica dos números.
- **División:** divide dos números e incluye manejo de errores para evitar la división entre cero.

```text
Calculadora_Individual/
│

```

## Requisitos
- Python 3 instalado.
- Visual Studio Code (para editar y ejecutar el proyecto).

## Cómo ejecutar el programa

1. Descargar o clonar el repositorio.
2. Abrir una terminal dentro de la carpeta del proyecto.
3. Ejecutar el siguiente comando:

```bash
python main.py
```

4. Ingresar los dos números solicitados.
5. Seleccionar la operación que se desea realizar.
